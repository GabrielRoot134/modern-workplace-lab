# New Hire Onboarding

## Scenario

A new employee joins the company and requires access to Microsoft 365 services.

### Employee Information

Name: Sarah Johnson

Department: Marketing

Job Title: Marketing Coordinator

## Tasks Completed

- Created user account
- Assigned Microsoft 365 license
- Enabled MFA
- Added user to security group
- Verified Outlook mailbox creation
- Verified Microsoft Teams access

## Outcome

The employee was successfully onboarded and granted access to company resources.
