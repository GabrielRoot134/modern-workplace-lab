# MFA Troubleshooting

## Scenario

A user is unable to access Microsoft 365 because they cannot complete Multi-Factor Authentication (MFA).

## User Report

The user receives the MFA prompt but is unable to approve the sign-in request.

## Investigation

- Verified user account status
- Confirmed MFA was enabled
- Checked registered authentication methods
- Verified Microsoft Authenticator registration

## Resolution

The user re-registered Microsoft Authenticator and successfully completed MFA verification.

## Outcome

User regained access to Microsoft 365 services.
